# handoff/prayer

Everything Claude Code needs to build the prayer app into the hub.

| File | What it is |
|---|---|
| `PROMPT.md` | Paste this into Claude Code, from the repo root |
| `TASKS.md` | The ordered task list with acceptance checks |
| `SPEC.md` | What the app is and why each decision was made |
| `prayer.html` | Working, tested prototype — build from this |
| `prayers.json` | A real data export, showing the exact shape |
| `check.js` | `node handoff/prayer/check.js apps/prayer.html` — 31 behaviour checks |

The seed data is placeholder. The real list is kept out of the repo on purpose — paste it into the app once it is live.
