Warm as a Hearth, clear as glass.

Paper, glass and the person's own colour. Every hub screen and every new app is built from what's on this page.

Themes

Six named palettes, each one neutral block (the nine colour families are per scheme): Hearth (warm grouped neutrals), Parchment (soft tan reading paper), Frost (cool pale glass, iOS grouped), Midnight (warm dark), Forest (deep green, gold ink) and Graphite (true black). System is Hearth by day and Midnight at night. The theme follows the person; pick one at the top of this page to preview everything below in it. Each swatch carries data-theme-preview, data-scheme and data-accent.

Colour

Neutrals per palette, nine house pastel families for people and nine for apps, each with eight roles (wash, fill, fill-strong, strong, graphic, ink, ink-hi, on), and semantic success / warning / danger. Text and icons always use -ink; a solid carries its own -on label; marks use -graphic. A person is data-accent on any element.

Contrast (WCAG AA)

Computed live from the rendered colours in this theme; the accent pairs are checked for every family colour.

Type

Bold system titles (SF Pro on Apple devices), the serif only for adults' reading text, rounded numerals for everyone and rounded everything for kids. The Dynamic Type roles scale with the iPad, the person's text size and the kind.

Liquid glass

v3 glass is built in layers: a specular sheen along the top edge, a darker refracted ring inside and a lighter one outside, an inner shadow at the bottom, a little of the person's colour caught in the pane, and a blurred, saturated view of whatever sits behind. The sheen drifts with scroll and tilt (--sheen-x, set by hub.js). Chrome (tab bar, sheets, composer) keeps real blur; cards inside a scrolling page paint the same look without blurring, which is what keeps an iPad smooth.
